# superskill 是什么？（说人话版）

> 给不搞技术的自己看的版本。专业版请见 [README.md](README.md)。

## 一句话

**superskill 是一个"整理 AI 技能的工具"。** 就像你家抽屉太多、东西太乱，它帮你把同类东西归到一个抽屉里，贴上标签，以后想用哪个一眼就能找到。

## 打个比方

你手机里装了一堆 App：

- 视频类：剪映、快手、B站……
- 文档类：WPS、Word、PDF阅读器……

用的时候你从不会想"先想清楚用哪个 App"——因为它们是**按类型分好类**的，你一看图标就知道。

superskill 就是给 WorkBuddy 里的"AI 小技能"做**同样的事**。

## 为什么需要它？

WorkBuddy 里的小技能会越攒越多，比如：

- 有三四个都是"做视频"的，名字还都不一样
- 有两个都是"打开网页操作"的
- 有一个是做表格的、有一个是做图的……

时间一长，乱到连 AI 自己都容易搞混：该用哪个？会不会用错？

## 它能帮你做什么？

1. **先扫一遍**：把你电脑里所有的 AI 技能列个清单（叫什么、干嘛用的）
2. **分门别类**：把"都是做视频的"归成一堆，"都是处理文档的"归成一堆
3. **问你一句**：这么分行不行？（你说行才动手）
4. **合并收拢**：每一类合成一个"大门类"，小技能都收进去
5. **验收**：确认没丢东西、没搞乱

## 结果长什么样？

之前：技能列表几十个，密密麻麻，AI 也容易选错。

之后：就剩几个大门类——"视频制作""文档处理""浏览器操作"……AI 一看就知道该进哪个门，进去再找具体的小技能。

## 会不会把我东西搞坏？

**不会，而且留了后悔药。**

- 动手前会先给你看一份"迁移清单"，你确认了才真动
- 每次操作都记一笔账（`manifest.json`），万一不满意，按账本一步就能还原
- 原来的技能文件一个都没删，只是挪了个地方放好

## 用起来麻烦吗？

不麻烦，一条命令扫描、一条命令归类，剩下都是 AI 和你在聊天里确认。
